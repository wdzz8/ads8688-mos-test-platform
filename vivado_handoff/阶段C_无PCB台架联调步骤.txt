阶段 C：PCB 到货前的模块台架联调
============================================================

目标
在没有自制 PCB 的情况下，先用 AX7020、ADS8688 模块、MCP4725 模块、OPA192
模块、INA240 模块和万用表/示波器，逐段证明低能量信号链。当前不接 DPS、不接
MOS 功率回路，不把任何电源输出直接接到 ADS8688 输入。

当前已完成
1. ADS8688 CH0 SPI 通信已验证，5V 供电下接地和3.3V输入均能得到合理码值。
2. MCP4725 I2C 通信已验证，输出三角波。
3. MCP4725 VOUT 回接 ADS8688 后，ILA 已观察到随 DAC 变化的波形。

本阶段新增的 FPGA 版本
scripts/build_mos_monitor.tcl
output/mos_adc_monitor/mos_adc_monitor.bit
output/mos_adc_monitor/mos_adc_monitor.ltx
该版本把 ADS8688 八个通道的最近采样值分别保存为 adc_ch0~adc_ch7，
用于确认 J16 和 ADS8688 实际通道映射。它仍然只输出低压 DAC 三角波，
不控制 DPS，也不驱动 MOS。

第一步：断电检查
------------------------------------------------------------
1. AX7020、ADS8688、MCP4725、OPA192、INA240 全部断电。
2. ADS8688 AVDD/VCC 只接5V；MCP4725只接3.3V；OPA192按模块要求接+5V/-5V；
   INA240按模块要求接5V。所有模块GND和AX7020 GND共地。
3. ADS8688 DAISY在模块端接GND。
4. MCP4725 SDA=AX7020 J11-10，SCL=J11-9；确认SDA/SCL各有2.2kΩ~4.7kΩ上拉到3.3V。
5. ADS8688 SPI仍按J11-3/4/5/6/7连接。

第二步：先单独验证 OPA192 电源
------------------------------------------------------------
1. 不接信号线，只接OPA192电源和公共GND。
2. 以OPA192模块丝印和实际原理图为准确认电源针脚；文档中J7/J13曾出现过
   不一致，不能仅凭历史编号盲接。
3. 上电前用万用表电阻档确认+5V、GND、-5V之间没有短路。
4. 上电后测：VDD对GND约+5V，VEE对GND约-5V。若极性或数值错误立即断电。

第三步：MCP4725 到 OPA192 的低压链路
------------------------------------------------------------
1. 先下载本目录 output/mos_adc_monitor/mos_adc_monitor.bit 和同目录 ltx。
2. MCP4725 VOUT接OPA192 SMA-IN；OPA192 SMA-OUT先只接万用表/示波器，不接MOS。
3. 执行 scripts/capture_mos_monitor.tcl，观察DAC输出和ADC通道。
4. 理想情况下SMA-OUT随MCP4725 VOUT缓慢在约0~3.3V变化；若OPA配置为跟随器，
   SMA-OUT应接近SMA-IN。若反相/放大，按实测电阻比重新计算，不直接套用跟随器结论。
5. 每次只改一个连接，记录SMA-IN、SMA-OUT和对应ADC通道的电压。

第四步：确认 ADS8688 通道映射
------------------------------------------------------------
1. 对每个候选输入逐一施加GND、3.3V和OPA输出，其他输入保持不接或按模块资料接地。
2. 观察 adc_ch0~adc_ch7，记录哪个通道随输入变化；不要把“AIN8”直接当成芯片通道，
   ADS8688芯片通道只有AIN0~AIN7。
3. 将实测结果填入“通道映射记录.csv”。必须按实际J16丝印、模块原理图和万用表通断结果
   三者核对，不能只依赖旧文档里的通道编号。

第五步：INA240 小信号验证
------------------------------------------------------------
1. 暂时不接MOS和DPS。用已知低压、限流的测试电流通过0.1Ω采样电阻；最大电流先限制在
   1mA以内，确认电阻功耗和接线方向。
2. 按INA240模块丝印确认VCC、GND、IN+、IN-、OUT，不能仅按编号猜测。
3. 测INA240 OUT对GND，确认没有饱和、振荡或异常负压，再接ADS8688候选输入。
4. 记录已知电流、采样电阻压降和INA输出，拟合 I = (VOUT - offset)/(Gain*Rshunt)。
   A1模块的真实增益必须以芯片丝印/数据手册确认，不默认某个增益。

第六步：DPS/M1 暂缓
------------------------------------------------------------
在确认DPS/M1具体型号、IN/OUT关系、是否隔离、通信接口和故障输出之前，禁止把12V
接入MOS漏极回路。先发送型号照片、端子丝印和数据手册，才能确定J10-1/J10-2及
使能/故障接线。RS232/RS485不能直接接AX7020 LVCMOS33；USB D+/D-也不能直接接普通IO。

判定标准
------------------------------------------------------------
本阶段通过条件：
- OPA192电源极性正确，输出无明显振荡。
- MCP4725 VOUT和OPA192 SMA-OUT的变化方向、幅度已记录。
- ADS8688 八个通道中，实际 J16/输入映射已经逐路确认。
- INA240 输出在安全小电流下可重复，增益和零点已记录。
- 未接DPS/MOS前，所有模拟输入均不超过ADS8688实际配置范围。

通过后再做
1. 修改FPGA通道映射和每通道量程参数。
2. 增加DAC扫描点表、静态采样和数据保存。
3. 使用限流DPS和假负载验证漏极回路。
4. 最后才接2N7000并实现VGS转移曲线、VDS输出曲线和工作区判断。
