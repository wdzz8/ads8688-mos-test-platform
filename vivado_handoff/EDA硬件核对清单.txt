EDA硬件核对清单
============================================================

原理图输入
[ ] AX7020型号、器件封装和J11针脚方向已与实际板卡核对。
[ ] FPGA器件为xc7z020clg400-2；50MHz时钟为U18。
[ ] ADS8688 SPI五根线按J11-3/4/5/6/7连接，方向没有接反。
[ ] ADS8688 DAISY在模块端接GND，没有连接到FPGA IO。
[ ] ADS8688模块使用5V；AX7020接口和MCP4725使用3.3V逻辑/供电要求已分开。
[ ] MCP4725 SDA=J11-10/J18，SCL=J11-9/H18，SDA/SCL上拉到3.3V。
[ ] MCP4725 A0电平已确认；若不是GND，更新I2C地址和软件配置。
[ ] MCP4725 VOUT连接ADS8688 AIN0/P2-4，AIN0没有并接固定电源。
[ ] OPA192、INA240、MOS和采样电阻的模拟电源、输入共模和输出范围已计算。
[ ] DPS型号、USB/TTL UART/RS-232/RS-485接口类型已确认。
[ ] DPS故障输出、输出使能、急停和硬件关断路径已定义。

PCB输入
[ ] SPI、I2C和模拟输入线远离DPS开关节点与MOS大电流回路。
[ ] ADC模拟输入滤波、地回流和保护器件已按最终模块原理图确认。
[ ] 采样电阻使用Kelvin走线；INA240输入对称，功率地不穿过小信号地。
[ ] 各模块电源脚附近去耦已布置，5V/3.3V电源容量和压降已核算。
[ ] 外接连接器有明确Pin1标识、防反插和丝印信号名。
[ ] UART/RS232/RS485使用正确收发器和电平，USB D+/D-没有接普通FPGA IO。
[ ] 外部模拟端口有合适的ESD/过压/限流保护，且不影响ADC输入范围。

Vivado交接
[ ] 使用project/dac_adc_loopback.xpr打开工程。
[ ] 使用constr/dac_adc_loopback.xdc，未与旧工程XDC重复或冲突。
[ ] bit和ltx为同一版本配对文件。
[ ] ILA probe0~probe9均能识别，capture_tick为每1ms保存资格。
[ ] init_done=1、init_error=0、dac_ready=1、dac_error=0后才判定通信正常。
[ ] DPS/触发/故障预留信号在接口确定前不得自行绑定到任意J11针脚。

上电测试顺序
1. 不接MOS功率回路，仅接AX7020、ADS8688、MCP4725并共地。
2. 先测5V和3.3V，再确认MCP4725 SDA/SCL空闲为高电平。
3. 下载匹配bit/ltx，确认LED3和ILA状态。
4. 测量VOUT是否在0~3.3V缓慢变化。
5. 将VOUT接AIN0，确认ch_data随VOUT变化。
6. 再接OPA192/INA240模拟前端，最后接DPS和MOS功率回路。
7. 任何过流、过压、过温异常时先关闭DPS，再保留波形和ILA日志。
