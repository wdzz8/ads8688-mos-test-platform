静态输出

复现步骤

  1. 安装 requirements.txt 中的 pyserial、matplotlib、numpy。
  2. 使用匹配的 mos_experiment.bit/.ltx 下载 AX7020。
  3. COM3 上 DPS 设置为 3 V、20 mA 上限，程序每轮自动关断并回读。
  4. 执行 python scripts/run_mos_demo.py 采集动态。
  5. 执行 python scripts/run_transfer_curve.py 采集恒 VDS 转移曲线。
  6. 执行分析与 bundle 构建命令，打开本页。

可以写进答辩的结论

  • FPGA 可控 DAC 栅压与 8 通道无平均采集链路已在真实 PCB 上运行。
  • 1、5、10 Hz 的实测周期分别约 0.99994、5.00020、10.00088 Hz，占空比约 0.5。
  • VDS 反馈把 9 个转移点保持在 0.5 V ± 15 mV 内，gm 随 VGS 上升。
  • 输出曲线的经验拟合保留留一验证，动态指标明确标注为整机系统响应。
不要宣称精密绝对电流、MOS 本征开关速度或 ADC FFFF 根因已被解决；这些边界已经在报告中记录。
