三条证据链

静态输出

4 个栅压 · 7 个漏极电压 · 每点 128 行，经验饱和模型留一点评估。

转移与跨导

VDS 反馈保持在 0.5 V 附近，9 个 DAC 栅压点提取有限差分 gm。

动态系统响应

FPGA 每 416 µs 采一组 8 通道，逐通道时刻保留，未平均。

固定 VGS 输出特性

横轴 VDS（源压扣零），纵轴 ID（名义换算）；圆点为实测，细线为经验模型 ID=A·VDS/(VDS+K)。

模型参数

每个栅压单独拟合；留一点评估来自其余六点。

VGSA / mAK / V留一 RMSE
这是用于展示和比较的紧凑经验模型，不能直接当作 MOS 本征参数或数据手册模型。

恒 VDS 转移曲线

主图横轴 VGS，纵轴 ID；每个点均保存原始 CSV，VDS 接受范围为 0.485–0.515 V。

提取结果

VGS / VVDS / VID / mAgm / mS
Vth proxy 对拟合电流范围敏感；页面将其标为趋势代理，不冒充 datasheet VGS(th)。

动态波形回放

选择频率。曲线为真实采样的 VG 与 VD 原始通道；采样是顺序扫描，CH0 到 CH7 相隔 364 µs。

复现步骤

  1. 安装 requirements.txt 中的 pyserial、matplotlib、numpy。
  2. 使用匹配的 mos_experiment.bit/.ltx 下载 AX7020。
  3. COM3 上 DPS 设置为 3 V、20 mA 上限，程序每轮自动关断并回读。
  4. 执行 python scripts/run_mos_demo.py 采集动态。
  5. 执行 python scripts/run_transfer_curve.py 采集恒 VDS 转移曲线。
  6. 执行分析与 bundle 构建命令，打开本页。

可以写进答辩的结论

  • FPGA 可控 DAC 栅压与 8 通道无平均采集链路已在真实 PCB 上运行。
  • 1、5、10 Hz 的实测周期分别约 0.99994、5.00020、10.00088 Hz，占空比约 0.5。
  • VDS 反馈把 9 个转移点保持在 0.5 V ± 15 mV 内，gm 随 VGS 上升。
  • 输出曲线的经验拟合保留留一验证，动态指标明确标注为整机系统响应。
不要宣称精密绝对电流、MOS 本征开关速度或 ADC FFFF 根因已被解决；这些边界已经在报告中记录。
