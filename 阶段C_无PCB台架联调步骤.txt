扫描版使用步骤（output/mos_scan）
------------------------------------------------------------
这一版在监视版基础上加了 VG 阶梯扫描，仍然不控制 DPS，漏极电压由外部电源手动给定。
默认参数：32 点、DAC 码 0 起、步进 128（约 0~3.2V）、每点稳定 20ms、每点平均 8 轮整扫，
一轮扫描约 0.85s，扫完停 200ms 自动重来。

1. 接线：MCP4725 VOUT 接 OPA192 SMA-IN（或先直接接模块AIN1/P2-4，即芯片CH0做回环），
   OPA192 SMA-OUT 接 ADS8688 对应的栅压输入；ADS8688 5V、MCP4725 3.3V、全部共地。
   不要接 DPS 和 2N7000 时先跑一遍，确认 VG 阶梯和通道读数正常。
2. 下载 output/mos_scan/mos_scan.bit 和同目录 mos_scan.ltx（必须同一版本）。
3. LED 含义（低电平点亮）：
   LED1 1Hz 心跳，闪 = FPGA 程序在跑；
   LED2 每完成一轮扫描翻转一次，约 0.85s 翻转一次，不翻转 = 扫描没起来；
   LED3 亮 = init_done 和 dac_ready 都正常且无错误，灭 = 有问题，先排错再抓数据。
4. 在 Hardware Manager 的 Tcl Console 执行：
   source C:/Users/wdz/Desktop/fpga/ads8688_1/scripts/capture_mos_scan.tcl
   每次抓 1024 行（1 行 = 1 个扫描点），约 34 秒，自动导出
   output/mos_scan/mos_scan_<时间戳>.csv和同名.ila。
   当前脚本直接导出，不打开波形窗口；本机Vivado 2022.2在display_hw_ila_data -reset处崩溃。
5. 画图：
   回环阶段用：python scripts/plot_mos_scan.py output/mos_scan/mos_scan_<时间戳>.csv --loopback --all
   输出逐点平均 csv 和曲线 png。CH_MAP、量程、INA240 增益和零点在脚本顶部 CONFIG 改。
   当前默认CH_MAP仍是早期台架假设；正式接PCB前需按模块编号转换和实测结果一起核对CH_MAP与量程。
   回环及OPA验证阶段使用--loopback；--all可查看CH0参考输入与CH1缓冲输出。
